# 一个主创新候选、两个支撑点

状态：拟验证贡献，尚未成立。本文用于明确研究问题和验收证据，不是论文结果。

## 工程问题

夹钳振动增强可能来自加载冲击、连接状态变化或摩擦持续供能。需要检验这些响应变化是否同时造成有效夹紧力或制动转矩损失，以及单一振动指标是否足以支持性能判断。

研究对象限定为杠杆式夹钳的主铰接连接。盘片初始间隙、销孔径向间隙、轴向游隙和螺栓预紧力是不同变量，不能统称为“松动”。

## 主创新候选：主铰接间隙状态下的传力性能预测与评价

### 对外提案表述

拟面向执行器输入一致而夹钳连接状态不同的工况，研究振动响应与实际传力性能可能不一致的条件，建立由间隙状态、输入历史及必要辅助测量支持的夹紧力/转矩预测，并检验其能否降低单一振动指标造成的性能判断偏差。

### 必须出现的增量

- 对照已有迟滞、等效空行程或低阶连接模型，证明新增状态或测量量带来独立预测改善。
- 在未用于标定的输入波形、加载速度或间隙状态下验证。
- 改善应超过数值误差、参数不确定性和实验重复性散布。
- 如要使用“误判”一词，须先定义被比较的判断规则与性能基准，并证明其确有误判；不能虚构行业普遍只看振动。

### 不能算增量的内容

加入间隙副、多体建模、增加若干参数工况、画FFT/相图，或换一套夹钳几何，本身都不足以构成主要创新。“振动大但平均力变化小”也不能仅凭一张图称为新机理。

## 支撑点一：振动来源的对照证据

拟对比严格理想铰与间隙铰，以及摩擦关闭、恒摩擦和经实测标定的速度相关摩擦。结合保持阶段响应、扰动衰减及能量流，检验振动由加载瞬态还是摩擦供能维持。

已有摩擦振动理论和控制变量方法是基础工具。只有其服务于上述主问题并增加可靠证据时，才有研究价值；不能把预设负斜率摩擦产生振动称为间隙的新机制。

## 支撑点二：结论适用边界

拟检查回位机构、初始盘片间隙、支承柔度、连接摩擦及附加活动惯性改变时，主结论的方向和幅度是否保持。

若“制动力下降”只在某个假设回位参数下出现，应报告条件性结果；若变化方向会反转，应说明边界，不强给统一规律。

## 建议用于开题的三句话

1. **研究问题：** 主铰接间隙引起的振动变化，能否可靠反映实际传力性能的变化？
2. **拟贡献：** 建立可独立验证的传力预测/评价，明确振动指标有效和失效的条件。
3. **成立标准：** 相对简单模型有可重复、超过不确定性的预测增量，并与可实施台架测量一致。

## 目前不成立的承诺

不能承诺本方向没有先例、必然产生混沌、间隙必然导致平均制动力下降、十分钟即可完成验证，或保底某个期刊分区。最接近论文的全文核验、参数来源与实验条件仍会决定是否值得继续。
