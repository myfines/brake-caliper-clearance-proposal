# 最小验证路线与停止条件

## 1. 先确认连接的物理含义

识别实际支承和传力路径，分别记录销孔径向间隙、轴向游隙、盘片初始间隙与回位状态。确认连接件是自由转动销轴、肩部螺栓还是依赖预紧摩擦传力的夹紧连接。

扭矩百分比不能直接替代已知预紧力。不能仅因外形有螺栓头，就设置任意“松动百分比”并推论真实故障。

## 2. 保留真正的对照

- 严格理想铰，而非接触罚刚度下的柔性零间隙。
- 摩擦关闭、恒摩擦系数与经实测标定的速度相关摩擦。
- 非旋转加载冲击与旋转保持；人工指定初态与连续加载自然形成的初态分别记录。
- 必要的回位、支承柔度及活动件惯性对照。

先评价总体传力，不以局部应力云图作为主要贡献。只有整体预测需要时，才增加柔性自由度。

## 3. 输入输出与指标

优先输入实际气缸推力，并同步测压力与行程；输出左右法向夹紧力、总夹紧力、制动转矩/转速及可实现测点的振动。

共同目标夹紧力下分别报告首次到达与持续达标时间，固定时间窗累计夹紧力、保持阶段均值和波动、卸载残余及回碰。积分窗口和目标值在比较前固定，不以各工况自身末态归一化掩盖不足。

振动强度、平均夹紧力和平均制动转矩是不同量；不得用其中一个的变化自动替代另外两个。

## 4. 简单模型必须参加比较

建立等效空行程或低阶迟滞基线。标定与验证工况分开，限制新增拟合参数。比较其与间隙接触模型在独立工况中的误差，说明复杂模型究竟增加了什么。

若复杂模型只多画出冲击波形，而总体性能预测没有可靠改善，不能直接称为主要创新。

## 5. 自激与混沌的证据边界

保持阶段振动、扰动增长/衰减和能量流可用于研究稳定性。FFT峰值一致不能唯一验证机理，相图也不能单独证明混沌。

任何新增摩擦曲线或等效模态，都必须说明其来源和影响。即使假设模型能自激，也不代表实物会自激，更不代表间隙是原因。

## 6. 成立与停止

**可以继续：** 主铰接状态带来超过实验散布和参数不确定性的性能差异；复杂模型相对简单基线有独立预测增量；对照实验能够区分竞争机制。

**需要收窄：** 只在局部输入或回位条件下成立，或仅影响冲击而不显著影响总体性能。保留条件，不外推。

**应停止当前创新主张：** 近邻已覆盖；效应可由初始盘片间隙或回位完全解释；简单模型已足够；效应低于测量散布；关键参数无法标定或实验无法实施。

最终结论分别写“模型支持什么”“实验支持什么”“尚未知什么”。研究提案和概念试算均不能冒充已经成立的实验证据。
